# 2027 年度台中南區地區友好總會

邁向創立一百週年 勇躍前進之年

## 功能

22 地區總會與彩排時間進度、個人釘選、會議紀錄、工作分工、人數統計、籌備進度、幸福1+1稿件與PPT本機保存、幹部姓名查詢，以及紀錄匯出與匯入。

## 使用方式

網站可由 GitHub Pages 開啟。選擇地區後輸入及儲存紀錄；釘選的地區會固定顯示。

目前為可操作版本，各人的紀錄保存在自己使用的瀏覽器，尚未提供多人同步。檔案保存在瀏覽器 IndexedDB，尚未自動上傳 Google 雲端。雲端資料夾連結可在各地區設定後開啟並手動上傳。

從本機移轉到線上網址前，請先匯出 JSON 紀錄備份，再到新網址匯入。檔案本體請個別下載，JSON 不包含檔案；個人釘選也需重新設定。

## 維護

修改 app.js 或 styles.css 後，執行 python3 build.py 產生獨立 index.html，再提交更新。詳細操作請參閱「使用說明.md」。

年度主題為 2027；本次活動實際安排於 2026 年 12 月。
