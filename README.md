# 2027 地區友好總會填寫網站

台中南區四部共用的運營紀錄填寫網站。

保留個人釘選、地區卡片、舉辦與彩排日期、時間進度條、搜尋篩選及地區總覽。地區工作區提供運營紀錄填寫、幸福1+1稿件與PPT上傳。

運營紀錄確認送出後，自動將內容帶入今年的 Word 範本，依選取週次上傳到指定資料夾。其他幹部使用原有 Google 雲端資料夾取檔。網站不提供雲端資料夾入口、位置設定或管理總覽。

網站直接填寫送出，無需代碼。網站只提供送入服務，不提供匿名讀取他人運營紀錄或空白範本；文件仍由原有 Google 雲端權限控管。`cloud-config.json` 只保存 Apps Script 服務網址。設定 `testMode:true` 可使用獨立測試資料庫；正式網站為 false。

`build.py` 組合 `styles.css`、`cloud-client.js`、`app.js` 成為 `index.html`。Word 空白範本保存在私人 Google 雲端資料夾，由私人服務直接產生 Word，不傳回網站；不放到公開網站或 GitHub。`cloud/Code.gs` 是 Google 服務原始碼，管理員設定與代碼雜湊只注入私人的 Apps Script 專案。

自動產檔、指定週次歸檔、稿件上傳與跨瀏覽器讀取已用獨立測試資料驗證。

運營 Word 檔名使用「光興地區－10月26日－第一次運營紀錄表.docx」格式，依地區、日期與運營次數自動調整。防重複識別碼保存在檔案說明與系統紀錄，不放進完成檔名。


## 相關下載

地區工作區第四個功能為「相關下載」，開啟時不會自動下載。正式沙推表、彩排沙推表、正式程序表與彩排檢討表各有獨立按鈕與 PDF。

正式沙推表依正式總會時間選用早上（09:30）、下午（14:00）或晚上（19:50）範本，重新讀取共用資料後，在瀏覽器產生兩頁 A3 橫式 PDF。檔案只含該場次的正式沙推表；灰色表頭在正反面重複顯示工作組負責人，內文帶入對應擔當者與總結幹部。未確認者保留待確認，幸福1+1 提報人選在定稿前不帶入。

內容來自提供的 Excel 範本，網格資料存於 `assets/sandplay-grid.json`。PDF 只讀取資料，不會寫入會議紀錄、雲端檔案或試算表。字型及 PDF 元件均隨網站提供，授權文字位於 `assets/vendor/`。PDF 預設原尺寸、依頁面選紙、雙面短邊翻頁；印表機是否採用這些偏好仍取決於設備支援。

彩排沙推表採 A3 橫式單頁，依該區彩排日期、時間與場地推算流程；正式程序表採 A4 直式單頁，歡迎進場從正式開始前 30 分鐘起算。彩排檢討表採 A4 直式單頁，帶入程序人員，保留計時及建議空格。新表結構來自 `assets/related-grids.json`，由 `related-pdf.js` 產生。新表完整嵌入本機字型，以避免稀疏網格的中文字形缺漏；既有正式表維持字型子集。

各文件均重新讀取已儲存資料，依地區與文件類型保留直接下載連結。缺少唱導、彩排指導或頒獎前輩明確資料時顯示待確認，不從其他職務推定。

驗證：`node tests/sandplay-pdf.cjs`、`node tests/related-pdf.cjs`、`node tests/sandplay-download.cjs`、`node tests/cloud-input-preservation.cjs`。
